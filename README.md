# Login & Sign-Up Form 🔐

A simple and clean **Login and Sign-Up Form UI** built using **HTML5 and CSS3**. The project demonstrates form design, input fields, radio buttons, checkboxes, CSS styling, gradient backgrounds, and navigation between login and registration pages.

## 📌 Project Overview

This project contains two web pages:

* **Login Page** — Allows users to enter their email/phone and password.
* **Sign-Up Page** — Provides a registration form for entering personal and account information.

The interface uses a **blue-to-purple gradient background** with a centered form container for a modern and simple appearance.

## ✨ Features

### 🔑 Login Form

* Email/Phone input field
* Password input field
* Login button
* Navigation link to the Sign-Up page

### 📝 Sign-Up Form

* Personal information fields
* Gender selection using radio buttons
* Date of birth field
* Mobile number field
* Email address field
* Password field
* Confirm password field
* Terms and Conditions checkbox
* Navigation link back to the Login page

### 🎨 UI Features

* Blue-to-purple gradient background
* Clean and simple layout
* Rounded form container
* Styled input fields
* CSS-based form design
* Navigation between multiple HTML pages

## 🚀 How to Run

1. Clone or download this repository.
2. Make sure `index.html` and `SignUp.html` are in the same folder.
3. Open **`index.html`** in any modern web browser.
4. Click the **Sign Up** link to open the registration page.
5. Use the **Log In** link to return to the Login page.
